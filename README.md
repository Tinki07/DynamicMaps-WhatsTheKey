# DynamicMaps - What's The Key

Add-on for [DynamicMaps](https://github.com/acidphantasm/SPT-DynamicMaps).

Right-click a locked door on the map to search its key on the flea market.

- Works out of raid, from the map in the character screen
- Uses the same search as the "Filter by item" item action, so it also works for keys you can't buy yet
- Going back from the flea market brings you back to the map
- Can be turned off in the config (F12): `General > Enabled`

## Requirements

- SPT 4.1
- DynamicMaps 1.3.0 or newer

## Installation

Extract the zip into your SPT folder. The DLL goes in `BepInEx/plugins/tinki07-whatsthekey/`.
